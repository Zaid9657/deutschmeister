point to be declared `new` in the unit where the spine places it. GRM-01 counts the spine's placements even when a
unit does not declare them. So with the blueprint row order, unit 1 (work) would have to teach Dativ prepositions and
Imperativ *Sie*, and unit 2 (the way) *war/hatte*. The series beat fixes unit 1 as the way-finding scene too.
`spine.md` §6 already logs this: "the reconciliation onto the §2.8 rows must keep this file's intro units". The spine
owner therefore owns the logged reorder, so no unit carries a `deviation` for it.

The can-do ids of `cando-a1.md` §2 were **re-assigned by topic** onto the spine order. No id was invented, and each
id is core in exactly one unit.
