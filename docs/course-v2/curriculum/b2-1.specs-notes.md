## 6. Lexicon blocks

Each unit has 4 block titles with `target` counts and `lemmas: []` (lemma ids come from the lexicon allocator).
Targets per unit = the plan's `vocabTarget` of the draft unit (u08 = E8, u10 = 66): 66–67, total 799, inside
`targets.newWords` [720, 840] (level profile 60–70 per unit × 12; BLUEPRINT §2.6 700–850).
**Schema conflict (for the SCHEMA owner and the lexicon allocator):** UnitSpec caps `lexiconBlocks` at 3–4 blocks ×
6–10 lemmas (≤ 40 per unit), while the B2 profile needs 60–70 new lemmas per unit and LEX-05 requires every allocated
lemma in a block. The same cap breaks B1 (≈ 45 per unit). Until SCHEMA widens the cap (e.g. `{6..20}` from B1), the
blocks here carry the targets the profile implies. `target` is a transient authoring key (as in `a2.1/specs.json`);
it is not a SCHEMA field and must be removed when the lemma ids are filled.
