## 1. Unit order: U5 and U6 swapped against BLUEPRINT §2.8

| id | here | BLUEPRINT §2.8 row | W2 draft |

**Why.** The two registries use different numberings for these two units. `grammar-spine.json` introduces
`g.pronomen-er-es-sie` + `g.adjektiv-praedikativ` at `a1.1-u05` (Wohnung) and `g.akkusativ` + `g.kein` at `a1.1-u06`
(with `chunkFrom` `g.praep-dativ` „im Wohnzimmer" at u05 and `g.dativverben-pronomen` „Kannst du mir … geben?" at
u06) — the W2 draft order. `cando-a1.md` §2 keys its table to the blueprint rows (u05 = Brauchen, u06 = Wohnung).
GRM-02 reads intro positions from the spine, and the can-do registry itself carries no unit, so the only order that
keeps every registry fact true is the spine's. The can-do sets travel **with their situation**: the Wohnung core set
of cando-a1.md row `a1.1-u06` is used at `a1.1-u05`, and the Brauchen core set of row `a1.1-u05` at `a1.1-u06`.
BLUEPRINT §2.8 allows a swap of situations inside a level with a logged `deviation`; both units carry one.
