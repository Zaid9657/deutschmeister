The author is right that `rule_patches` only reaches `grammar_rules`, so this cannot be fixed from an EXTEND file. **But a straight field swap is not the fix and would ship a broken item:** each German string names its own answer, so after swapping, `question_de` reads "Welche Präposition bedeutet 'wegen'?" with key `wegen`, and "Welches Relativpronomen bedeutet 'deren' …?" with key `deren` — both self-answering. The orchestrator should apply, outside this deliverable, a hand-written `UPDATE public.grammar_exercises` (guarded on id + the current values) that swaps the fields **and rewrites the German** so it no longer contains the key, e.g.

- gen-prep oi 7 → `question_de`: "Welche Präposition nennt einen Grund?" / `question_en`: "Which preposition gives a reason? (options: trotz / wegen / während / statt)"
