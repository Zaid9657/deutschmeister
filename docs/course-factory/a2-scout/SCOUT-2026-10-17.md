### 3B. Constructions and the never-lists

### 3C. The word-order harness (`scripts/a12-determinacy.mjs`) is main-clause only

The harness that proves "every correct word order the German prompt allows is accepted" (and whose
`openingOf` / `middleFieldOrders` the builder imports for the determinacy repairs,
`build-lesson-pool.mjs:138`) generates alternatives for **statements with one main clause only**:

* `wordOrderAlternatives` (`:74`) — header `:45`: "Statements only — no question, no imperative, no
  second clause"; `:83` returns `[]` for any key with an inner comma, `;`, `:`, `?`, `!` or the words
  `und/oder/aber/weil/dass/wenn`. A coordinated second clause after `, denn/aber/sondern/oder/und` is
  handled (`:79-81`) by varying the first clause only.
* `middleFieldOrders` (`:154`) — same exclusions plus `denn` and **any negation** (`nicht/nie/kein…`);
  pronouns are held fixed and only 2–3 movable constituents are permuted.
* `MODAL_LEMMA` (`:23-30`) knows the present modal forms only, not `konnte/musste/wollte`.
* The builder runs the determinacy repairs only for a level with `determinacyRepairs: true`
  (`build-lesson-pool.mjs:340`; A1.2 row `:950`).

What A2 adds that the harness cannot see: a subordinate clause in either position (`Weil ich krank
bin, bleibe ich zu Hause.` = `Ich bleibe zu Hause, weil ich krank bin.`), the A2.1 pronoun-order rule
(`Ich gebe es ihm.` / `Ich gebe ihm das Buch.`), indirect questions and `zu`-infinitive clauses (all
carry a comma), negated statements, and the Präteritum modals. 73 of the 242 built A2.2 items sit
in the two subordinate-clause topics and `indirect-questions-intro` (25 + 25 + 23, §1.3), 97 with
`infinitive-with-zu-intro` (24); for every one of them the harness reports "0 rejected alternatives"
because it generates none, which reads as determinacy and is blindness. Shared code; the clause splitter has to come before A2.2 items are
reviewed. (The file name says A1.2, the functions take a level: `servedItems(level, …)` `:279`.)

### 3D. The answer checker (`src/lib/lesson/check.js`) — measured with the real function

`measure/check-probe.mjs` calls `checkAnswer` of `662ffa2` exactly as a typed item does:

| Learner typed | Key | Result | Should be |
|---|---|---|---|
| hatte / konnte / wurde | hätte / könnte / würde | **typo** (×3) | wrong — the umlaut IS the Konjunktiv II |
| Ich hatte gern einen Kaffee. | Ich hätte gern einen Kaffee. | **typo** | wrong |
| Konnten Sie mir helfen? | Könnten Sie mir helfen? | **typo** | wrong |
| alter / Mein Bruder ist alter als ich. | älter / … älter als ich. | **typo** (×2) | wrong — the comparative umlaut |
| den neuem Tisch · einen neue Tisch · auf den Tisch · eingekaufen · weil ich bin krank · Ich freue dich | (the correct forms) | wrong (×6) | wrong — correct already |
| Die Wohnung kostet 850 Euro. *(dictation)* | … achthundertfünfzig Euro. | **wrong** | correct — digits for a heard number |
| Ich bin 1990 geboren. *(dictation)* | … neunzehnhundertneunzig … | **wrong** | correct |
| Wir ziehen am 3. Mai um. *(dictation)* | … am dritten Mai um. | **wrong** | correct |

Causes: `normalizeAnswer` (`src/utils/answerMatch.js:13-21`, unchanged on both branches) folds
`ä→ae`, so `hatte`/`haette` are one edit apart, and the typo rule (`check.js:281-282`) forgives one
edit on a word of ≥ 5 letters unless an inflectional ending changed (`ENDINGS`, `:158`;
`endingDiffers`, `:162`) — an umlaut change is not an ending. That forgiveness was a deliberate A1
decision (a missing umlaut on a foreign keyboard, REVIEW #2 §E, comment at `:170-177`); at A2.2 it
erases two grammar points. The ending rule itself already serves A2 well (adjective endings,
`dem/den`, participles come back wrong). Dictation numbers fold only 0–100 and two-digit compounds
(`DICTATION_NUMBERS` `:71-76`, `NUMBER_RE` `:85-88`): A2 dictations with rents, years or dates refuse
digits. `STRICT_TOPIC` (`:178`) is a slug-name regex (`article|possessive|pronoun|plural|kasus|case`):
it matches `dative-case`, `possessive-pronouns` and `pronouns-accusative-dative`, not
`adjective-endings-intro`, `comparative` or `konjunktiv-ii-polite` — harmless for endings (the ending
rule catches them), relevant for umlauts. The spelling fold (`SPELLED_OUT_RE` `:123`) only fires for a
letter-by-letter key and does not touch A2. A per-item or per-topic "umlaut is grammar" switch is the
smallest fix; it is shared code that also scores live A1.1, so it needs the A1.1 pins re-measured.

### 3E. The checkpoint builder (`src/lib/checkpoint/buildCheckpoint.js`)

* **The Lesen report transformer reads A1 present tense.** Engine "ich" of `reportSentence`
  (`:1606ff`) reports a speaker's line about a third person only when the word after „Ich" is a key
  of `VERB_3SG` (`:1627-1628`), a hand table of ~40 present-tense A1.1/A1.2 verbs plus `möchte` and
  `will` (`:1377-1420`). Not in it: every Präteritum (`war`, `hatte`, `konnte`, `musste` — 1st and
  3rd person are the same form, so they were never added; „Ich war krank." yields no report), the
  modals `kann/muss/darf/soll`, and every A2 verb a dialogue will put after „Ich". `REPORT_STOP`
  (`:1430-1440`) kills any line containing `mich`, `mir`, `uns`, `euch` or a second `ich` — i.e.
  every reflexive („Ich freue mich …") and every dative-pronoun line, the core of A2.1/A2.2. A trailing
  `, denn/aber/weil …` clause is cut off rather than converted (`:1614`); a line that opens with a
  subordinate clause has no engine. `PARTICIPLE_RE` (`:1012`) misses separable participles
  (`eingekauft`) and strong inseparable ones (`verstanden`, `bekommen`). `CONTRARIES` (`:1026`) and
  `firstPersonForms` (`:1513`) are A1 vocabulary. Effect: A2 dialogues — narrated in Perfekt and
  Präteritum, full of `mir/mich` — offer few reportable sentences, and the Lesen section falls back to
  the fixture path the comment above `VERB_3SG` describes (quoting the text), which is what DaF review
  #3 for A1.2 flagged before A1.2's verbs were added.
* **The checkpoint's own writing task is looked up in the A1 exam bank only.**
  `checkpointWritingTask` (`:2234-2240`) calls `writingTaskByKey('goethe_a1', …)` and maps every task
  onto `formular` or `mitteilung`; `chapterWritingTask` (`:2219-2227`) tries the level's course tasks
  first, then the same `goethe_a1` bank. An `a21-cp1` task filed under `goethe_a2` returns `null`, so
  the A2 checkpoint loses its graded text (and `sectionPasses` then judges Schreiben without it).
  Shared code; the exam key has to come from the curriculum (`examKey`).
* Apart from the two `goethe_a1` calls, the file carries no level literal (grep at `662ffa2`: the
  other `a1.1`/`a11` hits are comments), so the paper draw, the `minLektion` filter and the pass rule
  read the curriculum and the pool. Its vocabulary tables are A1 all the same: `NUMBER_WORDS`
  (`:742`, 0–100) for the Hören number items, `CONTRARIES`, `TIME_ADVERBS` (`:1006`).

### 4.2 The order

0. **Owner decision: the A2 ceiling and who owns which bank topic** (§1.7). Standard §2.2 + M7 put

1. **Ship A1.2 and branch A2 from `main` after it.** It carries the level-aware draw gate

7. **Checker and checkpoint (shared code, touches live A1.1).** An "umlaut is grammar" switch for

8. **Per-level registries in the UI and the audio script (shared code, can wait for promotion, but

9. **Per-level data the teams then own (no engine change):** the curriculum module and its twin,
