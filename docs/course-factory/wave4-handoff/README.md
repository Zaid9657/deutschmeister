# Wave 4 handoff carrier

Reference material only — never merge this branch into main. It carries the reviewed, accepted
Course Factory Wave 4 (A2.1) deliverables that lived in an ephemeral session scratchpad, so a fresh
session on any account can finish the wave. Start with `HANDOFF-PROMPT.md`.

- `scratchpad/` — briefs, the binding level constraint, integration checklist, per-area deliverables
  (grammar, vocab, reading, listening, exam, test, plan) with their reviews and notes, source dumps,
  and the small helper scripts (chunkers, hash helper). Screenshots and regenerable apply-chunks are omitted.
- `pending-migrations/` — the two generated PR C migrations, identical to the ones on PR #85.

Delete the branch and close its PR when the wave is closed.
