## The blind corpus

Codex wrote it without seeing the checker, the keys or the course: 586 tasks (every servable A1.1
item, every A1.2 sentence-building and correction item, every tile set either checkout serves), 2,262
learner answers, each with a verdict and a reason. The first attempt was discarded because Codex
generated answers with a script; the second brief forbids scripts and runs read-only in batches.
Everything is in `blind-corpus-2026-11-19/` with its grader (`node grade-corpus.mjs <repo>
<this folder> [--main <main checkout>]`) and classifier.

- **Paired (the 1,204 lines both checkouts can grade, same prompt):** correct answers rejected
  155 → 142 (13 now accepted, 0 newly rejected); wrong answers accepted 4 → 4.
- **Tiles:** main rejected 281 of 338 correct orders of the lines it served; the branch serves only
  lines whose orders it can license, and its 40 remaining rejections are all one class (statement
  tiles rebuilt as a question).
- **Branch disagreements, adjudicated by written rules (`classify.mjs`):** 31 only the repaired word
  typed (input now says „Ganzer Satz"), 44 „an dem / in dem" for „am / im" (meaning changes: „an dem
  Freitag" is *that* Friday — not adopted), 20 a phrase after the final verb part (not neutral
  written German), 17 another preposition that changes the meaning, 24 letter names or articles
  added to spelling answers, 4 digits in a number task, 6 „er/sie" for das Kind in a generic
  sentence, 40 tiles as above, 11 fronted orders still accepted although the prompt names the
  opening (lenient; kept). The 113 unclassified were read one by one: broken umlauts from Codex's
  output encoding, the orders the middle-field rule refuses on purpose, dropped „Uhr" from a given
  chunk, vocative „Du," before an imperative, and a few debatable forms listed under follow-ups.

The corpus is deliberately generous (it calls „Wir aus Marokko kommen." correct), so it is a
detector, not the bar; the bar remains a fresh Codex evaluation of 7.5 or more with no BLOCKER or MAJOR.
