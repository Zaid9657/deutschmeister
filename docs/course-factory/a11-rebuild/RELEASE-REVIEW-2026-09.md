# DeutschStart A1.1 — named human release review

This is the release-evidence document required by
`docs/superpowers/plans/2026-09-15-deutschstart-a11-course-readiness.md` Task 4
and enforced by `tests/a11-release-review.test.mjs` (run via
`npm run verify:a11-release`).

A **qualified DaF reviewer** completes it after reviewing all 12 lessons, the
four checkpoints, the final test, audio samples from every lesson, and the 12
mission scripts. **No agent may fill these fields in** — an empty or
non-APPROVED document keeps the release gate red, which is the point. The 23
adversarial reviews under this directory are internal AI-assisted QA; this
document is the named human sign-off they are not.

```text
Reviewer name:
Qualification:
Review date:
Materials reviewed:
Verdict: PENDING
Signature or verifiable approval reference:
```

Verdict must be exactly `APPROVED` for the gate to pass; anything else
(including `PENDING` or `REJECTED`) keeps DeutschStart A1.1 unsellable as a
premium course.
