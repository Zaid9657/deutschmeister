# Die drei Prompts

Ein Prompt pro Plattform, nicht pro Clip — du tauschst nur den Textblock aus
`texte/<slug>/clip-N.md` aus.

| Datei | Plattform |
|---|---|
| `yt-shorts.md` | YouTube Shorts |
| `ig-reels.md` | Instagram Reels |
| `fb-reels.md` | Facebook Reels |

**Die eine Grenze, die für alle drei gilt:** eine Browser-Erweiterung kann den
Datei-Dialog des Betriebssystems nicht bedienen. Das Hochladen der Videodatei
machst immer du. Alles danach — Titel, Beschreibung, Einstellungen,
Veröffentlichen — übernimmt die Extension.

Reihenfolge pro Clip:

1. Datei aus `clips/` von Hand hochladen.
2. Warten, bis die Textfelder da sind.
3. Prompt einfügen, die beiden `<<< … >>>`-Blöcke vorher durch den Text aus
   dem Textblatt ersetzen.
4. Nach dem Veröffentlichen den ersten Kommentar von Hand setzen.
