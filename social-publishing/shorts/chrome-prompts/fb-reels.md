# Chrome-Extension-Prompt — Facebook Reels

**Vorher von Hand:**

1. `facebook.com` öffnen, im **Meta Business Suite** oder direkt auf der
   Seite **Deutsch Meister** (nicht im privaten Profil).
2. **Reel erstellen** → Datei aus `clips/` wählen.
3. Warten, bis der Schritt mit dem Beschreibungsfeld sichtbar ist.
4. Erst dann den Prompt einfügen.

---

## PROMPT (ab hier alles kopieren)

Du arbeitest im geöffneten Facebook-Reel-Editor auf der Seite Deutsch
Meister. Das Video ist bereits gewählt. Fülle alles exakt so aus, wie es
hier steht. Erfinde nichts, kürze nichts, übersetze nichts.

**Schritt 1 — Beschreibung**

Feld „Beschreibung": exakt einsetzen, mit allen Zeilenumbrüchen und
Leerzeilen:

```
<<< CAPTION AUS DEM TEXTBLATT, ABSCHNITT „Facebook Reels" >>>
```

**Schritt 2 — Einstellungen**

- Keine Musik hinzufügen. Wenn ein Musikvorschlag erscheint: ablehnen oder überspringen.
- Keine Sticker, keine Texteinblendungen, keine Filter.
- Falls „Auch auf Instagram teilen" angeboten wird und das Konto verknüpft ist: **einschalten**.
- Zielgruppe: **Öffentlich**.

**Schritt 3 — Veröffentlichen**

„Veröffentlichen" drücken. Nicht planen, nicht als Entwurf speichern.

**Schritt 4 — melden**

Sag mir in einem Satz: ist das Reel veröffentlicht, und wie lautet der Link?
Wenn etwas anders aussieht als beschrieben, sag mir genau was — rate nicht.

**Was du nicht tust**

- Nichts im privaten Profil posten, nur auf der Seite Deutsch Meister.
- Keine anderen Beiträge ändern oder löschen.
- Keine Werbeanzeige schalten, keinen Beitrag bewerben, nichts bezahlen.
- Keine Seiteneinstellungen ändern.
