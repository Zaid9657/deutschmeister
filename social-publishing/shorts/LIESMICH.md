# Shorts & Reels — ٥٥ مقطعًا من ١١ فيديو

كل شيء جاهز ما عدا خطوة واحدة: **القص نفسه يجب أن يتم على جهازك**، لأن
جلسة Claude السحابية محجوبة عن Supabase (سياسة الشبكة موثّقة في `CLAUDE.md`).
لذلك السكربت موجود هنا جاهزًا، وأنت تشغّله بأمر واحد.

---

## ما الذي في هذا المجلد

| الملف | ما هو |
|---|---|
| `schneiden.sh` | سكربت القص — ماك/لينكس |
| `schneiden.ps1` | نفس السكربت — ويندوز |
| `schnittliste.txt` | قائمة الـ٥٥ مقطعًا التي يقرأها السكربت |
| `schnittplan.csv` | نفس القائمة بشكل جدول للمراجعة |
| `texte/<slug>/clip-N.md` | ورقة نص لكل مقطع: عنوان + وصف + هاشتاغات لكل منصة |
| `chrome-prompts/` | ثلاثة prompts لإضافة Claude في المتصفح |
| `veroeffentlichen.md` | خطة النشر: الترتيب، الوقت، والممنوعات |
| `daten.mjs` | مصدر كل النصوص — عدّل هنا وأعد التوليد |

## الخطوات

### ١ — ثبّت ffmpeg (مرة واحدة فقط)

```
ماك:      brew install ffmpeg
لينكس:    sudo apt install ffmpeg
ويندوز:   winget install Gyan.FFmpeg
```

### ٢ — جرّب على فيديو واحد أولًا

```bash
cd shorts
./schneiden.sh 1
```

يحمّل الفيديو الأول ويقص منه ٥ مقاطع في `clips/`.
**افتحها وشاهدها.** إن كانت اللقطة بدأت في مكان غير مناسب، افتح `daten.mjs`
وغيّر الرقم `anker` لذلك المقطع (نسبة مئوية من طول الفيديو)، ثم:

```bash
node texte-erzeugen.mjs
rm clips/01-*.mp4
./schneiden.sh 1
```

### ٣ — شغّل الباقي

```bash
./schneiden.sh
```

يحمّل الـ١١ فيديو (حوالي ٢٧٠ ميغابايت) ويقص ٥٥ مقطعًا. المقاطع الموجودة
مسبقًا يتخطاها، فيمكنك إيقافه ومتابعته لاحقًا.

الناتج: `clips/*.mp4` — عمودي 1080×1920، ٥٠ ثانية لكل مقطع، خلفية ضبابية من
الفيديو نفسه، بدون نص محروق وبدون موسيقى.

### ٤ — انشر

لكل مقطع: افتح ورقته في `texte/`، ارفع الملف يدويًا، ثم الصق الـprompt من
`chrome-prompts/` في إضافة Claude.

الإضافة **لا تستطيع** فتح نافذة اختيار الملفات في نظام التشغيل — رفع الملف
خطوتك أنت دائمًا. بعدها تتولى هي العناوين والوصف والإعدادات.

## ما لم أستطع التحقق منه

- **لم أشغّل السكربت** — لا ffmpeg في هذه الجلسة ولا وصول إلى الفيديوهات.
  المنطق مفحوص نحويًا وقراءة القائمة مجرّبة، لكن التشغيل الفعلي أول مرة
  عندك. لهذا الخطوة ٢ على فيديو واحد قبل الـ٥٥.
- **لم أشاهد الفيديوهات** — لذلك النقاط (`anker`) نسبية وليست توقيتات مؤكدة.
  توقّع أن ٥–١٠ مقاطع ستحتاج تعديل رقم، وهذا طبيعي.
- الفيديو رقم ٣ (`mastering-der-die-das`) حجمه مطابق تمامًا لرقم ٥ في الجرد —
  يُحتمل أنه نسخة مكررة من فيديو الضمائر. **افتحه قبل نشر مقاطعه.**

## نصيحة واحدة

المقاطع ليست الهدف، الوصول هو الهدف. مقطع واحد يوميًا لمدة شهرين يتفوق على
٥٥ مقطعًا تُنشر في أسبوع ثم صمت. التفاصيل في `veroeffentlichen.md`.
