# 50 posts for Instagram, Facebook and Telegram: one a day, Zapier-ready

**Status: 50 posts rendered, scheduled 2026-10-01 → 2026-11-19, 18:00 Berlin.**
The first 3 are the samples the owner approved on 2026-09-27; the other 47 follow
the same template and voice. Nothing self-publishes until the daily Routine
(`ROUTINE.md`) is switched on with the target account IDs.

The directory name says 100 because that was the first brief. The owner cut it to
50 on 2026-09-27, and the name stays so earlier links still work.

## What is where
| File | What |
|---|---|
| `content.py` | the source: every post's card text, caption, link, series; the rotation and dates |
| `samples.json` | the 3 approved samples, verbatim (ids 001–003) |
| `posts.json` | generated by `content.py`, the input for the two scripts below |
| `render.mjs` | cards → `public/social/ig/NNN.jpg` (served at `deutsch-meister.de/social/ig/`) |
| `captions.mjs` | `posts.json` → `posts.csv`, one row per post, three channels |
| `ROUTINE.md` | the daily publish prompt (one row per day via the Zapier connections) |

## Format
- **1080×1350 JPEG (4:5).** That is the tallest ratio Instagram's publishing API
  accepts, and Zapier goes through that API. The 3:4 profile grid only trims the
  sides, so every card keeps a 96px margin. The renderer shrinks any card whose
  content would overflow, and fails if it cannot fit.
- Brand: `src/data/design-tokens.js` with Fraunces and Nunito Sans inlined. Case
  colours only appear where a case is named (token rule 1).
- Six series in proportional rotation, never two of the same series in a row:
  Satz des Tages 10, Fehler-Check 10, Redemittel 9, Wortschatz 7, Prüfungs-Fakt 7,
  Lerntipp 7.
- Claims: every exam fact is quoted from `astro-site/src/data/guides/*.js`
  (factsCheckedOn 2026-08-22). There are no outcome promises, no fees and no usage
  numbers. Every link was checked against the grammar cache and guide registry.

## Sheet columns (`posts.csv`)
`post_id, status, publish_at, series, image_url, alt_text, caption_instagram,
caption_facebook, caption_telegram`. Instagram captions say "Link in Bio" because
links in captions are not clickable there. Facebook and Telegram captions carry
`?utm_source=<channel>&utm_medium=post&utm_campaign=ig50-2026-10&utm_content=p<id>`,
so the Monday truth mail shows which post brought each signup.

## Rebuild after an edit
```bash
python3 content.py && node render.mjs && node captions.mjs
```
